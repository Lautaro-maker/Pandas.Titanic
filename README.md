# DA.Titanic.SurvivalAnalysis

Titanic dataset analysis and exploratory data visualization using Python, Pandas, and Seaborn. The project analyzes survival rates by age groups, gender, and passenger class using relative frequencies and demographic distributions. Proyect url: https://roadmap.sh/projects/titanic-eda-python

📖 Project Description
This project consists of a Python script developed within the Jupyter Notebook interactive environment. Its main objective is to perform exploratory data analysis (EDA) on the Titanic passenger dataset, cleaning age features, handling data types, and calculating relative survival rates.

The processed data is visualized using specialized plotting libraries like Seaborn and Matplotlib to uncover demographic insights, such as the impact of age, gender, and passenger class on survival probabilities.

🛠️ Technologies and Libraries Used

* Python 3: Main programming language.
* Jupyter Notebook: Interactive development environment.
* Pandas: For data manipulation, grouping, and feature engineering.
* Seaborn & Matplotlib: For generating comparative distribution plots and relative frequency visualizations.

⚙️ Requirements and Installation
To run this project in your local environment, make sure you have Python installed. Then, follow these steps:

* Clone the repository: Download the code from GitHub to your computer using the terminal:
`git clone [YOUR_REPOSITORY_URL]`
`cd [PROJECT_FOLDER_NAME]`
* Install necessary dependencies (Pandas, Seaborn, Matplotlib, Jupyter).

🚀 How to Run the Project
Since the source code is in an interactive file, you must start it via the Jupyter server:

* Open your terminal in the root folder where the project is located.
* Start the local Jupyter Notebook server: `jupyter notebook`
* A tab will open in your web browser. Click on the main file (the one with the .ipynb extension).
* Run the code cells in sequential order (you can use Shift + Enter cell by cell or run all from the menu).
